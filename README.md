# Inland Marketing Group — Website

Marketing agency website for Inland Marketing Group (IMG), serving the Inland Empire, CA.

- **Stack:** a single self-contained `index.html` — all CSS, JavaScript, and SVG artwork inline. No build step, no dependencies.
- **Theme:** red (#C8102E), black, and white on a white background, with custom Inland Empire artwork (San Bernardino mountains, palms, citrus groves).
- **To view:** open `index.html` in any browser, or serve the folder with any static server.
